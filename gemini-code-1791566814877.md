# 🧞‍♂️ EduGenie: Google Gemini Powered Learning Assistant

EduGenie is a lightweight, full-stack AI study assistant built with **FastAPI** and **Google Gemini 1.5 Flash**. It provides personalized academic support, practice quiz generation, and automatic note summarization.

---

## 🌟 Key Features

- **💬 Interactive AI Tutor:** Step-by-step explanations for complex academic concepts and homework.
- **📝 Instant Quiz Generation:** Automatically creates customized multiple-choice practice quizzes on any topic.
- **📄 Note Summarizer:** Converts lengthy lecture notes or textbook excerpts into structured key takeaways.
- **⚡ Modern Responsive UI:** Tailwind CSS frontend rendering clean Markdown output via FastAPI Jinja2 templates.
